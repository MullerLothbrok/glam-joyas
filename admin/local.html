Ingresar con GitHub

Después de ingresar, elegí «Lista de precios del local» en el panel.

Los precios del local son precios normales al público. La promoción web se muestra por separado. Necesitás internet para consultar y guardar. Para entrar rápido, agregá esta página a la pantalla de inicio de tu celular desde el menú del navegador.

Joya del local

Se guarda de forma privada. No aparece en la web hasta que lo publiques.

Las opciones de esta ficha comparten precio. Si tienen precios diferentes, cargá una ficha por pieza.

Publicar esta joya

El nombre, la foto, las opciones y el precio pasarán al repositorio público y al catálogo online. La web aplica su promoción actual del 10%. Aunque después archives la pieza, sus versiones anteriores pueden permanecer en el historial público.
